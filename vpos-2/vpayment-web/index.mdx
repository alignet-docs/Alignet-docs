VPayment Web es el sistema administrativo que permite a los usuarios autorizados del comercio consultar y operar sobre las transacciones registradas durante el proceso de autorización.

<Warning>
  Esta guía no aplica a comercios en Perú. V-Payment se ofrece regionalmente y la operación puede variar por país. Para confirmar el procedimiento correspondiente, escribe a [integraciones@alignet.com](mailto:integraciones@alignet.com).
</Warning>

## Qué puedes hacer

- Consultar el detalle y estado actual de los pedidos.
- Identificar motivos de denegación o datos inválidos.
- Extornar pedidos autorizados, según los permisos y reglas del adquirente.
- Preparar lotes para el procesamiento de Base II o liquidación.
- Generar reportes personalizados.
- Administrar usuarios y sus accesos.
