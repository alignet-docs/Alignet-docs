## Instalar el módulo

La guía v2.2 referencia el módulo PrestaShop 2.0.9. Solicita al adquirente el paquete vigente y confirma su compatibilidad antes de instalarlo.

<Card title="Descargar plugin para PrestaShop" icon="download" href="https://github.com/alignet-docs/alignet-prestashop-int_1/releases/latest/download/PrestashopPluginPaymeCheckout.zip" cta="Descargar plugin" arrow={false}>
  Descarga la última versión oficial del plugin Pay-me Checkout para PrestaShop.
</Card>

<Frame caption="Paquete oficial del módulo Pay-me Checkout para PrestaShop.">
  ![Descarga del módulo Pay-me Checkout](/images/vpos2-prestashop-descarga.jpg)
</Frame>

1. Ingresa al administrador y abre **Módulos → Module Manager**.
2. Selecciona **Subir un módulo**.
3. Elige el archivo ZIP oficial, instálalo y completa la activación.

## Configurar Pay-me Checkout

En **Módulos → Module Manager**, localiza Pay-me Checkout dentro de los métodos de pago y abre su configuración. Durante la certificación selecciona **Integración**.

<Frame caption="Acceso a la configuración de Pay-me Checkout.">
  ![Ubicación del módulo Pay-me Checkout](/images/vpos2-prestashop-configuracion-1.png)
</Frame>

<Frame caption="Parámetros principales del módulo.">
  ![Configuración de Pay-me Checkout en PrestaShop](/images/vpos2-prestashop-configuracion-2.png)
</Frame>

| Parámetro | Origen o criterio |
| --- | --- |
| Ambiente | **Integración** durante instalación y pruebas. |
| ID adquirente e ID comercio | Entregados por el adquirente. |
| Clave VPOS | Contenido de la llave `PASARELA`. |
| Clave Wallet | Solo cuando Wallet esté habilitado. |
| Moneda local | Primer bloque de configuración. |
| Dólares | Segundo bloque de moneda extranjera. |
| URL de respuesta | Compártela con el equipo de Integraciones. |

<Frame caption="Configuración por moneda.">
  ![Bloques de configuración por moneda](/images/vpos2-prestashop-configuracion-monedas.png)
</Frame>

- El método de pago aparece habilitado.
- El ambiente activo es **Integración**.
- IDs y llaves corresponden al mismo comercio y ambiente.
- La moneda de la tienda coincide con el bloque configurado.
- La URL de respuesta fue registrada.
