## Datos requeridos

Solicita a tu adquirente:

1. **ID Adquirente**.
2. **ID Comercio**.
3. Acceso administrador del comercio a **VPayment web**.

| Ambiente | VPayment web |
| --- | --- |
| Integración | `https://integracion.alignetsac.com/vpaymentweb/index.jsp` |
| Producción | `https://vpayment.verifika.com/vpaymentweb/index.jsp` |

## Generar las llaves

En VPayment web abre **Administración → Llaves Públicas y Privadas**, selecciona **Registrar Llaves** y confirma **Registrar y descargar**.

![Generación y descarga de llaves SHA-2 para Redirect](/images/vpos2-redirect-generar-llaves.gif)

`LlavesSHA2.zip` contiene:

* `*_PASARELA_*.txt`: llave SHA-2 necesaria para firmar y validar VPOS-2.
* `*_WALLET_*.txt`: úsala solo si Wallet fue activado para el comercio.
* Archivos RSA públicos y privados: no se requieren para Redirect.

<Warning>
  Cada registro de llaves reemplaza inmediatamente las anteriores. Conserva el ZIP de forma segura y regenera únicamente cuando sea necesario o según la política del comercio.
</Warning>
