Before you start, make sure you have completed the phase of [Access to the Platform](/en/virtual-payments/prestashop/introduction) and count with the file **.zip** module Alignet One for PrestaShop.

The installation of **Alignet One Gateway** is performed natively through the module manager PrestaShopThat guarantees a clear integration with your staff's hooks.

## Module Download

Be sure to download the latest version published by the computer Alignet One:

<Card title="Download module Alignet One for PrestaShop" icon="download" href="https://github.com/alignet-docs/alignet-payme-prestashop/releases/latest">
  Download the latest official release from GitHub Reforms. The current version is **v1.1.0** and the published file is **payme.zip**.
</Card>

***

## Installation process

Follow these steps inside your management panel:

<Steps>
  <Step title="Access back office">
    login on your PrestaShop with an administrator's credentials.
  </Step>

  <Step title="Module Manager">
    On the left side menu, go to **Modules** > **Module Manager** (or Module Manager).
  </Step>

  <Step title="Up Module">
    Click the button **Upgrading a module** Located at the top right of the screen.
  </Step>

  <Step title="Select File">
    Drag the file **payme.zip** Or get it on your computer. The system will start decompression and automatic load.
  </Step>

  <Step title="Finish and Go to Setup">
    Once the message "Module installed" appears, click the button **Configure** To get your credentials.
  </Step>
</Steps>

***

## Installation Verification

To confirm that the module is activated and recognised by the system:

1. Go to **Modules** > **Module Manager**.
2. At the search bar, write **"Alignet One"**.
3. Make sure the switch's at **activated**. If you see a button that says "Enabling," click on it.

<Card>
  **Failed up?** Check that your server allows uploading at least 10MB and that folder **/ modules /** of your installation PrestaShop have write permits **(755 or 775)**.
</Card>
