### General Validation of Success

Regardless of the processor used, your system's logic should be strict to avoid fraud or misconduct.

<CardGroup cols={2}>
  <Card title="Alignet approval" color="#10b981" icon="circle-check">
    Code **00**
  </Card>

  <Card title="External Processors" color="#3b82f6" icon="envelopes-bulk">
    Code **000**
  </Card>
</CardGroup>

<Note>
  Any code other than those mentioned above should be treated automatically by its business logic as a transaction **Not Adopted**.
</Note>
