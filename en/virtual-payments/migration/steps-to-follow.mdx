---
title: "Steps to migrate"
description: "Procedure for installing Alignet Gateway, removing the previous version, and preparing the gateway to process payments."
icon: "route"
---

Follow these five stages to migrate to **Alignet One** in an orderly manner.

<Steps>
  <Step title="Prepare the update">
    Confirm the following before making changes to the store:

    <CardGroup cols={2}>
      <Card title="New gateway file" icon="file-zipper">
        Have the `.zip` file provided by Alignet ready. Do not unzip it.
      </Card>
      <Card title="Site backup" icon="database">
        Include the files and database, or at least `wp-content/plugins/`.
      </Card>
      <Card title="Administrator access" icon="user-shield">
        The user must be able to install and remove WordPress plugins.
      </Card>
      <Card title="Low-traffic window" icon="clock">
        Avoid peak sales periods while making the change.
      </Card>
      <Card title="Merchant registration data" icon="key">
        Have the information required to register the merchant in Alignet Command Center available.
      </Card>
    </CardGroup>

    <Warning>
      **Do not continue without a backup.** You must be able to recover the site if the installation does not finish correctly.
    </Warning>
  </Step>

  <Step title="Merchant registration data">
    The plugin configuration values are generated when the merchant registration is completed in **Alignet Command Center**.

    1. Sign in to **Alignet Command Center** with an authorized account.
    2. Complete the merchant registration with the corresponding information.
    3. When registration is complete, immediately save the three values shown in the confirmation.

    <CardGroup cols={3}>
      <Card title="Merchant code" icon="store">
        The `code` identifier generated for the merchant. Enter it in the plugin's **Merchant Code** field.
      </Card>
      <Card title="Client ID" icon="id-card">
        The OAuth client identifier. Enter it in the plugin's **Client ID** field.
      </Card>
      <Card title="Client Secret" icon="key">
        The OAuth client secret. Enter it in the plugin's **Client Secret** field.
      </Card>
    </CardGroup>

    <Warning>
      **Save the credentials before continuing.** The `Client ID` and `Client Secret` are displayed when merchant registration is completed and will not be shown again. Store them securely and do not include them in screenshots, public documents, or support requests.
    </Warning>
  </Step>

  <Step title="Install the new plugin">
    1. Go to **Plugins → Add Plugin → Upload Plugin**.
    2. Select the `.zip` file and click **Install Now**.
    3. Activate **Alignet Gateway** and confirm that it appears as active.
    4. Only then, deactivate and remove the **previous WooCommerce plugin**.

    <Warning>
      **The order is important.** Do not remove the previous version until you verify that **Alignet Gateway** is installed and active.
    </Warning>

    <Frame>
      <img src="/images/migracion/versiones-plugin.png" alt="Alignet Gateway active and the previous plugin ready to be removed" />
    </Frame>

    *Alignet Gateway is active; the previous version is deactivated and ready to be removed.*
  </Step>

  <Step title="Enter the credentials">
    1. Open **Payments** in the WordPress sidebar.
    2. Find **Alignet Gateway**, confirm that it is active, and select **Manage**.
    3. Complete the configuration using the values saved when the merchant was registered in Alignet Command Center.
    4. Review the environment, currency, and display mode. Then click **Save changes**.

    Configure the following values for each enabled currency:

    <CardGroup cols={3}>
      <Card title="Client ID" icon="id-card" />
      <Card title="Client Secret" icon="key" />
      <Card title="Merchant Code" icon="store" />
    </CardGroup>

    <Info>
      **Field mapping.** Enter `code` as **Merchant Code**, then copy the **Client ID** and **Client Secret** into the fields with the same names. Complete the block for the currency you are configuring.
    </Info>

    <Frame>
      <img src="/images/migracion/menu-payments.png" alt="Payments option in the WordPress sidebar" />
    </Frame>

    *1. Open Payments.*

    <Frame>
      <img src="/images/migracion/administrar-gateway.png" alt="Manage option for Alignet Gateway" />
    </Frame>

    *2. Select Manage in Alignet Gateway.*

    <Frame>
      <img src="/images/migracion/configuracion-gateway-1.png" alt="General Alignet Gateway configuration" />
    </Frame>

    *3. Review the country, environment, and display mode.*

    <Frame>
      <img src="/images/migracion/configuracion-gateway-2.png" alt="Credential fields by currency in Alignet Gateway" />
    </Frame>

    *4. Complete the credentials for each currency and save the changes.*
  </Step>

  <Step title="Validate before finishing">
    The migration is complete when the configuration and payment flow work correctly.

    - **Configuration status:** Client ID, Client Secret, and Merchant Code appear as configured.
    - **Assisted test:** perform a test or sandbox checkout with support from the bank and Alignet.
    - **Error log:** open **WooCommerce → Status → Logs** and confirm there are no Alignet errors.
    - **Change control:** record the date, versions, and person responsible.
  </Step>
</Steps>
