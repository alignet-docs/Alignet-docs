### Parameters

<AccordionGroup>
  <Accordion title="Affiliation data">
    | Field                       | Type              | Mandatory | Description                                                     |
    | --------------------------- | ----------------- | ----------- | --------------------------------------------------------------- |
    | `action`                    | String            | Yes | Action to run. Values: `subscribe` / `update_subscription` |
    | `merchant_affiliation_code` | String            | Yes | Affiliation code generated by the merchant.                  |
    | `merchant_code`             | String            | Yes | Merchant code that starts Affiliation.                   |
    | `type`                      | String            | Yes | Affiliation type. It's only allowed `MANUAL`.                   |
    | `frequency`                 | String            | No | Frequency of Affiliation collection.                      |
    | `amount`                    | String            | No | Amount to charge.                                |
    | `maxAmount`                 | String            | No | Maximum amount for recurrent payments in cents.            |
    | `currency`                  | String (ISO 4217) | Yes | Payment currency. For example: `604` = PEN.                         |
  </Accordion>

  <Accordion title="Data of the recipient">
    | Field                                      | Type              | Mandatory | Description                                 |
    | ------------------------------------------ | ----------------- | ----------- | ------------------------------------------- |
    | `beneficiary.first_name`                   | String            | Yes | Recipient's first name.                   |
    | `beneficiary.last_name`                    | String            | Yes | Recipient's last name.                 |
    | `beneficiary.email`                        | String            | Yes | Email from the recipient.        |
    | `beneficiary.phone.country_code`           | String            | Yes | Telephone country code. For example: `51`.     |
    | `beneficiary.phone.subscriber`             | String            | Yes | The recipient's phone number.        |
    | `beneficiary.identity_document.type`       | String            | No | Type of ID. For example: `DNI`. |
    | `beneficiary.identity_document.identifier` | String            | No | Identification document number.          |
    | `beneficiary.identity_document.country`    | String (ISO-3166) | No | Country of issue of document. For example: `PE`.   |
    | `beneficiary.location.line_1`              | String            | Yes | Main address.                        |
    | `beneficiary.location.line_2`              | String            | No | Additional address.                   |
    | `beneficiary.location.city`                | String            | Yes | The town of residence.                       |
    | `beneficiary.location.state`               | String            | Yes | Department or region.                      |
    | `beneficiary.location.country`             | String (ISO-3166) | Yes | Code ISO from the country. For example: `PE`.             |
  </Accordion>

  <Accordion title="Additional fields">
    | Field                              | Type   | Mandatory | Description                                                           |
    | ---------------------------------- | ------ | ----------- | --------------------------------------------------------------------- |
    | `additional_fields.FACTURACION_ID` | String | No | Customer's ID or billing contract.                           |
    | `additional_fields.PLAN`           | String | No | Name or code of the plan referred to by the recipient.            |
    | `wallet.user_id`                   | String | No | Wallet user ID used to associate a card with the affiliation. |
  </Accordion>
</AccordionGroup>

### Affiliation response

<AccordionGroup>
  <Accordion title="Affiliation data">
    | Field                                   | Type              | Mandatory | Description                                    |
    | --------------------------------------- | ----------------- | ----------- | ---------------------------------------------- |
    | `success`                               | Boolean           | Yes | It indicates if the process was performed correctly. |
    | `affiliation.affiliation_id`            | String (UUID)     | Yes | A system-generated affiliation ID.   |
    | `affiliation.merchant_affiliation_code` | String            | Yes | Affiliation code generated by the merchant. |
    | `affiliation.merchant_code`             | String (UUID)     | Yes | Merchant code.                           |
    | `affiliation.state`                     | String            | Yes | Affiliation status. For example: `ACTIVE`.        |
    | `affiliation.type`                      | String            | Yes | Affiliation type. For example: `MANUAL`.             |
    | `affiliation.frequency`                 | String            | No | Charge frequency.                      |
    | `affiliation.amount`                    | String            | No | Affiliation amount in minor currency units.            |
    | `affiliation.max_amount`                | String            | No | Maximum amount allowed.                        |
    | `affiliation.currency`                  | String (ISO 4217) | Yes | Payment currency.                          |
  </Accordion>

  <Accordion title="Data of the recipient">
    | Field                                                  | Type   | Mandatory | Description                   |
    | ------------------------------------------------------ | ------ | ----------- | ----------------------------- |
    | `affiliation.beneficiary.first_name`                   | String | Yes | Recipient's first name.     |
    | `affiliation.beneficiary.last_name`                    | String | Yes | Recipient's last name.   |
    | `affiliation.beneficiary.email`                        | String | Yes | Email.           |
    | `affiliation.beneficiary.phone.country_code`           | String | Yes | Telephone country code. |
    | `affiliation.beneficiary.phone.subscriber`             | String | Yes | phone number.           |
    | `affiliation.beneficiary.identity_document.type`       | String | No | Type of document.            |
    | `affiliation.beneficiary.identity_document.identifier` | String | No | document number.          |
    | `affiliation.beneficiary.identity_document.country`    | String | No | Country of document.           |
    | `affiliation.beneficiary.location.line_1`              | String | Yes | Main address.          |
    | `affiliation.beneficiary.location.city`                | String | Yes | City.                       |
    | `affiliation.beneficiary.location.state`               | String | Yes | Department or region.        |
    | `affiliation.beneficiary.location.country`             | String | Yes | Country.                         |
  </Accordion>
