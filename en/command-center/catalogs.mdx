**Catálogos** contains three tabs: **Marcas** (brands), **Métodos de pago** (payment methods) and **Procesadores** (processors). Each offers filters, search and **Nuevo**, according to your permissions.

| Catalog | Fields observed in the form |
| --- | --- |
| Brands | Code, name and status. |
| Payment methods | Code, name, status and **El método requiere seleccionar una marca** (brand selection required). |
| Processors | Code, name, status, methods, brands, countries, channels and advanced settings. |

## Review a form

1. Open the relevant tab.
2. Select **Nuevo**.
3. Use only values approved by the technical owner. Codes are case-sensitive.
4. Check capabilities and dependencies.
5. Select **Cancelar** if you will not register the item.

Processor channels observed were E-commerce, POS and Card-on-file. Advanced settings include the forwarding institution code used for routing.

<Warning>Check filters, permissions and context before creating a record. An empty list does not prove that an item does not exist.</Warning>

<Note>Forms were inspected without saving changes. Creation and validation must be tested in an authorized environment before treating this guide as a definitive procedure.</Note>
