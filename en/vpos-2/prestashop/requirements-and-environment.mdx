## Requirements

* An operational or in-development website with valid SSL.
* A technical integration owner.
* A working PrestaShop installation.
* PHP extensions: OpenSSL, HASH with SHA-512, XML, and SOAP.

## Published compatibility

The guide lists PrestaShop 1.6.x and 1.7.x. Version 2.2 adds PrestaShop 1.7.8.8 compatibility, fixes a response-URL issue, and updates the Pay-me logo.

<Note>
  Ask the Integrations team for the current compatibility matrix before using newer versions.
</Note>

## Integration environment

The environment is available 24/7. Support operates from 09:00 to 18:00 on business days, using Peru time (GMT-5). Send test results to the assigned integrators.

- [ ] HTTPS works without certificate errors.
- [ ] PrestaShop works before installing the module.
- [ ] Required PHP extensions are enabled.
- [ ] Administrator access is available.
- [ ] The acquirer confirmed that this guide applies.
