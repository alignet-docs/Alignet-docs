---
title: "Recommendations and production"
description: "Practices for enabling the module in production."
icon: "rocket"
---

* Complete access, key generation, and configuration in integration.
* Prefer the Modal scheme.
* Share the response URL with the acquirer and Integrations team.
* Coordinate visual customization with Integrations.
* Back up settings and keys before switching environments.

| Environment | V-ADMIN |
| --- | --- |
| Integration | [integracion.alignetsac.com/vpaymentweb](https://integracion.alignetsac.com/vpaymentweb/) |
| Production | [vpayment.verifika.com/vpaymentweb](https://vpayment.verifika.com/vpaymentweb/) |

Confirm production credentials, change the module to **Production**, validate currencies, and register the production response URL.

<Warning>
  Do not reuse integration keys or enable real payments without acquirer confirmation.
</Warning>
