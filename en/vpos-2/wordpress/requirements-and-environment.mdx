## Before you begin

The merchant needs:

* An operational website or one under development. If no website exists yet, the merchant should at least maintain active social media accounts.
* A valid SSL certificate and HTTPS navigation.
* A technical owner responsible for installation, configuration, and testing.
* A working WordPress and WooCommerce installation.

<Warning>
  The source guide does not apply to merchants in Peru. Contact `integraciones@alignet.com` to confirm the integration method for another country.
</Warning>

## Compatibility listed for version 4.2

The base documentation lists certification from WordPress 4.9.x through 6.0.2 and WooCommerce 4.x through 6.9.4. The v4.2 update adds WordPress 6.1.1 and WooCommerce 7.4.1 compatibility.

<Note>
  Ask the Integrations team for the current compatibility matrix before installing the plugin on newer platform versions.
</Note>

## PHP extensions

| Extension | Purpose |
| --- | --- |
| OpenSSL | Secure communications and cryptographic operations. |
| HASH | Signature generation and validation, including SHA-512 support. |
| XML | XML processing required by plugin components. |
| SOAP | Communication with services that use this protocol. |

## Integration environment

* The test environment is available 24/7.
* Support is available from 09:00 to 18:00 on business days.
* Times use Peru time, GMT-5.
* Send test results to the assigned integration contacts.

## Checklist

- [ ] The site uses HTTPS without certificate errors.
- [ ] WordPress and WooCommerce work before plugin installation.
- [ ] Required PHP extensions are enabled.
- [ ] WordPress administrator access is available.
- [ ] A technical integration owner has been assigned.
- [ ] The acquirer confirmed that this guide applies to the merchant.
