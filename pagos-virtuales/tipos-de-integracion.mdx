## Decide según tu proyecto

| Si tu negocio tiene… | Elige… | Qué debes preparar |
| --- | --- | --- |
| Una tienda WooCommerce, PrestaShop o VTEX | E-commerce | Acceso administrativo y credenciales del comercio. |
| Un sitio web desarrollado a medida | Checkout Web | Desarrollo frontend y backend, URLs y notificaciones. |
| Una aplicación Android o iOS | SDK Mobile | Desarrollo móvil y backend, accesos y dispositivos de prueba. |

El esfuerzo depende de tu sistema, los métodos habilitados y las validaciones de tu comercio. Configurar un plugin no elimina tus responsabilidades de seguridad y operación.
