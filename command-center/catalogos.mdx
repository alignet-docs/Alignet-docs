El módulo **Catálogos** contiene tres pestañas: **Marcas**, **Métodos de pago** y **Procesadores**. Cada una ofrece filtros, búsqueda y la opción **Nuevo**, según tus permisos.

| Catálogo | Campos observados en el formulario |
| --- | --- |
| Marcas | Código, nombre y estado. |
| Métodos de pago | Código, nombre, estado y casilla **El método requiere seleccionar una marca**. |
| Procesadores | Código, nombre, estado, métodos, marcas, países, canales y configuración avanzada. |

## Revisar un formulario

1. Abre la pestaña correspondiente.
2. Selecciona **Nuevo**.
3. Usa únicamente valores aprobados por el responsable técnico. El código distingue mayúsculas y minúsculas.
4. Comprueba las capacidades y dependencias.
5. Selecciona **Cancelar** si no vas a registrar el elemento.

Para procesadores se observaron canales E-commerce, POS y Card-on-file. La configuración avanzada incluye el código de institución de reenvío utilizado para el enrutamiento.

<Warning>Verifica filtros, permisos y contexto antes de crear un registro. Una lista sin resultados no demuestra que el elemento no exista.</Warning>

<Note>Los formularios se inspeccionaron sin guardar cambios. La creación y sus validaciones deben probarse en un ambiente autorizado antes de utilizar esta guía como procedimiento definitivo.</Note>
