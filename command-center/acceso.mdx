## Antes de comenzar

Necesitas una cuenta habilitada por tu organización. No compartas tu contraseña ni utilices credenciales de otra persona.

## Ingresar

1. Abre [Command Center](https://command.alignet.io/login) y verifica el dominio.
2. Completa **Correo electrónico** y **Contraseña**.
3. Selecciona **Acceder al Command Center**.
4. Si aparece una verificación adicional, sigue el procedimiento habilitado para tu cuenta.

La pantalla ofrece **Recuperar acceso** y **Mantener sesión activa**. Evita mantener la sesión en equipos compartidos.

<Note>La recuperación de acceso y la verificación adicional no se ejecutaron durante la revisión de esta guía.</Note>

## Menú principal

| Módulo | Uso |
| --- | --- |
| Dashboard ejecutivo | Revisar indicadores y gráficos de la operación. |
| Gestión de entidades | Consultar comercios, adquirentes, facilitadores y gateways. |
| Catálogos | Consultar marcas, métodos de pago y procesadores. |
| Transacciones | Buscar operaciones y revisar sus intentos de pago. |
| Usuarios | Consultar y administrar accesos dentro de tu alcance. |
| Roles | Revisar los permisos asociados a cada rol. |

El menú lateral incluye **Fijar menú expandido**. La cabecera muestra la ruta del módulo y un control de modo oscuro.

## Si no encuentras una opción

Confirma tu organización y permisos con el administrador. Un módulo ausente o un control deshabilitado no significa necesariamente un error: puede depender del rol, de una selección previa o estar marcado como **Próximamente**.

## Compartir evidencias de forma segura

Antes de enviar una captura, oculta nombres, correos, documentos, cuentas bancarias, datos de tarjetas, claves e identificadores reales. No compartas contenidos técnicos de entrada o salida en canales públicos.
